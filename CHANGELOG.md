# Changelog

## 0.6.0
- New setting **Allow stowed ammo** (off by default): also use ammo inside backpacks and other containers.
- New setting **Most charges wins** (off by default): pick the battery or magazine with the most charges left.
- Fixed: the swap message could show the wrong charge count for a battery taken from a stack.

## 0.5.0
- Batteries and chem tanks above the weapon's grade are skipped (Player Core: weapons use batteries up to their own grade).
- Messages say "battery" / "chem tank" instead of "magazine".
- Clearer messages when the only fuller battery is stowed, and when loose rounds run short but more are stowed.

## 0.4.0
- Fixed the action icon showing as raw code in the reload chat card.

## 0.3.0
- New reload icon (loop arrow around three rounds).
- Fixed the button overlapping the page counter on the persistent HUD.

## 0.2.0
- Renamed to SF2e Quick Reload (id `sf2e-quick-reload`).

## 0.1.0
- First version: Reload button in PF2e HUD's token and persistent HUD.
